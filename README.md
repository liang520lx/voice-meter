# 声音仪表

声音训练用的实时仪表：手机打开网页，说话时实时显示音高和共鸣（F2），和自己的本音基准对比，进了目标区间亮绿灯。

- 阶段 1 共鸣：共鸣比本音高 8% 以上，音高不跟着跑（±2 个半音）
- 阶段 2 音高：音高进 165–190 Hz，共鸣不低于本音
- 录音只在本机浏览器里计算，不上传、不保存

拖长同一个元音时最准；说句子时共鸣数字会随字变化，看大方向。

开发：`node test-dsp.js` 用合成元音检查算法；`node selftest.js <wav> <png>` 用 Edge 假麦克风跑整页（要先在本目录起 `python -m http.server 8765`）。
